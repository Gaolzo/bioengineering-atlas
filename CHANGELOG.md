# Historial de versiones / Changelog

## 0.1.0 · 2026-11-08

Primera versión del MVP científico.

- Aplicación estática bilingüe con biblioteca, cronología, fichas moleculares, laboratorio, evidencia y coautorías.
- Selección de publicaciones históricas y recientes con fuentes, atribuciones, límites y exportaciones bibliográficas.
- Visualizaciones originales y recorridos de regulación, bioprocesos y fitoreguladores.
- Importador de listados de Google Scholar, auditoría de metadatos para revisión y configuración de compilación para Netlify.
- Documentación de investigación, licencias y mantenimiento.

Initial bilingual scientific MVP with sourced publication records, original visualizations, bibliographic tooling, and deployment configuration.
